Implement/complete these APIs:

1. POST /api/v1/compliance/analyze

Purpose:
Return a complete, explainable compliance report.

Behavior:
- Use the existing parsing and checker outputs from Phase 3.
- Aggregate all checker results.
- Calculate readiness score.
- Categorize issues by severity.
- Return:
  - overall_status
  - readiness_score
  - critical_issues
  - warnings
  - passed_checks
  - recommendations
  - needs_verification items

Readiness scoring:
- Start from 100.
- Critical issue: subtract 20.
- Warning issue: subtract 8.
- Info issue: subtract 2.
- Minimum score should be 0.
- Maximum score should be 100.

Status mapping:
- score >= 90 and no critical issues: submission_ready
- score >= 75 and no critical issues: needs_minor_fixes
- score >= 50: needs_major_fixes
- score < 50: not_ready

2. POST /api/v1/packages/generate

Purpose:
Generate an Overleaf-ready ZIP package.

Request should include:
- paper_id
- conference_id
- project_id optional
- package_type: neurips_overleaf

Behavior:
- Load parsed paper and compliance report if available.
- Generate LaTeX package using conference guideline profile.
- Generate:
  - main.tex
  - references.bib
  - README_OVERLEAF_INSTRUCTIONS.md
  - compliance_report.json
- Package all files into a ZIP.
- Return package metadata and download path.

3. GET /api/v1/packages/{package_id}/download

Purpose:
Download the generated ZIP package.

Behavior:
- Validate package_id.
- Return ZIP file response.
- Handle missing file cleanly with proper exception response.
