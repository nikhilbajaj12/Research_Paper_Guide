Frontend pages:

1. Dashboard page
Route:
/
or
/dashboard

Purpose:
Show PaperGuide AI overview and start analysis flow.

Must include:
- App title: PaperGuide AI
- Subtitle: Conference-Aware Research Paper Submission Assistant
- Start New Analysis button
- Supported conference card for NeurIPS MVP
- Future conference placeholders: CVPR, ICML, ACL, EMNLP

2. Conference selection page or section

Purpose:
Allow user to select target conference.

MVP behavior:
- Enable NeurIPS only.
- Other conferences should show "Coming soon".

Display:
- Conference name
- Submission portal
- Page limit
- Anonymous required
- Template requirement
- Checklist requirement

3. Paper upload page

Purpose:
Upload PDF, DOCX, or LaTeX ZIP.

Behavior:
- Select conference first.
- Upload file.
- Show selected file name and size.
- Call POST /api/v1/papers/upload.
- Store returned paper_id in frontend state.
- Show upload success/failure.

4. Compliance report page

Purpose:
Run analysis and display compliance result.

Behavior:
- Call POST /api/v1/compliance/analyze with paper_id and conference_id.
- Show readiness score.
- Show overall status.
- Show critical issues.
- Show warnings.
- Show passed checks.
- Show fix suggestions.
- Show needs_verification items.

UI sections:
- Score card
- Status badge
- Critical issues list
- Warnings list
- Passed checks list
- Fix suggestions panel

5. Package generation page

Purpose:
Generate Overleaf-ready ZIP.

Behavior:
- Call POST /api/v1/packages/generate.
- Show generated files list.
- Show download button.
- Call GET /api/v1/packages/{package_id}/download.
- Show README instruction summary:
  - Upload ZIP to Overleaf
  - Ensure neurips_2026.sty exists
  - Set main.tex as main file
  - Recompile from scratch if references do not appear

Podman setup:

Create backend Containerfile:

backend/Containerfile

Requirements:
- Use python:3.11-slim or python:3.12-slim
- Set workdir /app
- Copy requirements.txt
- Install dependencies
- Copy backend app
- Expose port 8000
- Run uvicorn app.main:app --host 0.0.0.0 --port 8000

Create frontend Containerfile:

frontend/Containerfile

Requirements:
- Use node:20-alpine
- Set workdir /app
- Copy package.json and lock file if present
- Install dependencies
- Copy frontend source
- Expose port 3000
- Run npm run dev or npm run start depending on setup
- For MVP local dev, npm run dev is acceptable

Create podman-compose.yml at project root.

Services:
1. backend
   - build: ./backend
   - containerfile: Containerfile
   - ports: 8000:8000
   - env_file: ./backend/.env
   - volumes:
     - ./backend/storage:/app/storage

2. frontend
   - build: ./frontend
   - containerfile: Containerfile
   - ports: 3000:3000
   - env_file: ./frontend/.env
   - depends_on:
     - backend

Podman commands in README:

1. Copy env files:
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

2. Build and run:
podman-compose up --build

or if using podman compose:
podman compose up --build

3. Backend health:
curl http://localhost:8000/api/v1/health

4. Frontend:
Open http://localhost:3000

5. Stop:
podman-compose down

or:
podman compose down
