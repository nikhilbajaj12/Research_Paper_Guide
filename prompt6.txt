Improve the PaperGuide AI frontend UI to make it look like a professional production-grade SaaS dashboard, not a simple one-page demo.

Current issue:
The current UI is too plain. It only shows a basic blue header, centered title, start button, and simple conference cards. Redesign it completely with a modern, polished, enterprise-grade look while keeping the existing app flow and backend integration intact.

Project context:
PaperGuide AI is a conference-aware research paper submission assistant. It helps users:
1. Select a conference such as NeurIPS
2. Upload a research paper PDF/DOCX/LaTeX ZIP
3. Analyze compliance against conference guidelines
4. View compliance issues and readiness score
5. Generate an Overleaf-ready ZIP package

Important:
Do not break existing API integration.
Do not remove existing functionality.
Do not implement fake backend logic.
Do not fabricate conference rules or results.
Only improve frontend UI/UX and component structure.

Design goal:
Create a modern professional UI similar to an AI SaaS product / enterprise dashboard.
