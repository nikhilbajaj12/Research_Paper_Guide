Supported input files:

- DOCX
- LaTeX ZIP

Implement these APIs:

1. POST /api/v1/papers/upload
Purpose:
Upload a paper file.

Behavior:
- Accept multipart file upload.
- Validate file extension.
- Validate file size using config.
- Save file to configured upload directory.
- Generate paper_id.
- Return paper metadata.

Response should include:
- paper_id
- file_name
- file_type
- file_size
- storage_path
- upload_status

2. POST /api/v1/compliance/analyze
Purpose:
Parse uploaded paper and run rule-based checks.

Request should include:
- paper_id
- conference_id

Behavior:
- Load paper by paper_id.
- Load selected conference guideline using conference_service.
- Parse paper based on file type.
- Run rule-based compliance checkers.
- Return compliance report.

Checks to implement in MVP:
1. Anonymity check
   - Detect email addresses.
   - Detect obvious author/company markers.
   - Detect acknowledgement section.
   - Return issue if found.

2. Page limit check
   - For PDF, detect total page count.
   - Compare against conference main page limit if available.
   - If main-content page detection is not implemented yet, mark as needs_verification.

3. Reference section check
   - Detect whether References / Bibliography section exists.
   - Return warning if missing.

4. Citation check
   - Detect basic citation patterns like:
     - \cite{}
     - [1]
     - (Author et al., Year)
   - Return warning if no citation pattern is found.

5. Template check
   - For LaTeX ZIP, check if expected style file name exists.
   - For NeurIPS, check for neurips_2026.sty if configured.
   - If missing, return issue.

6. Checklist check
   - For LaTeX ZIP, check whether checklist file or checklist section exists.
   - If not found, return warning or needs_verification.

7. Basic claims check
   - Detect numeric claims such as percentages, speedups, loss values, accuracy values.
   - Do not remove or rewrite anything.
   - Return warning that claim should be verified with experiment/reference.
   - This should be rule-based only, not AI-based.

Checker requirements:

- Function should accept ParsedPaper or extracted text.
- Detect email pattern.
- Detect known terms like author, affiliation, acknowledgement, company, organization.

page_limit_checker.py:

- If exact main content page count is unavailable, return needs_verification warning.

reference_checker.py:
- Detect references/bibliography section.
- Return passed or warning.

citation_checker.py:
- Detect basic citation patterns.
- Return passed or warning.

template_checker.py:
- For LaTeX ZIP only, check required template/style file.
- For non-LaTeX files, return needs_verification.

checklist_checker.py:
- Detect checklist in LaTeX files if possible.
- Return warning if missing.

claims_checker.py:
- Detect numerical claims.
- Return warnings with message:
